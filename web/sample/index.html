내 휴대폰 자동 수집 연결

  1. Play 스토어에서 MacroDroid 설치
  2. 매크로 추가 → 트리거 알림 → 알림 수신 → 앱: 메시지, 카카오톡, 쓰는 카드사 앱 → 텍스트 포함: 원
  3. 액션 → HTTP 요청 → 방법 POST → 아래 주소 붙여넣기
  4. 헤더 추가 → 이름 Authorization, 값은 아래 헤더 값 붙여넣기
  5. 본문(Content type: application/json)에 아래 내용 붙여넣기
  6. 휴대폰 설정 → 애플리케이션 → MacroDroid → 배터리 → 제한 없음
